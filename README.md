# 校园活动报名统计器

这是一个使用Python内置库实现的社团招新活动报名数据统计工具，可以分析报名人数、学院分布、性别比例和时间趋势等信息。

## 功能特点

- **数据输入**：支持从CSV文件导入或手动输入报名数据
- **数据分析**：
  - 统计各学院报名人数及占比
  - 按性别分类统计报名人数
  - 分析报名时间高峰期(TOP3)
- **报告生成**：生成包含统计结果和简要分析的文本报告
- **数据保护**：包含个人信息隐私保护方法分析

## 使用方法

1. 运行程序：
```
python campus_registration_analyzer.py
```

2. 在菜单中选择相应操作：
   - 生成示例数据
   - 从CSV文件加载数据
   - 手动输入数据
   - 分析数据
   - 生成并显示报告
   - 保存报告到文件
   - 查看个人信息隐私保护分析

## 数据格式

CSV文件格式要求包含以下列：
- 姓名
- 性别
- 学院
- 报名时间

示例：
```
姓名,性别,学院,报名时间
张三,男,信息学院,19:30
李四,女,文传学院,20:15
```

仓库内的 `sample_data.csv`、截图和示例报告均为演示数据，不对应真实报名者。导入真实数据时建议先将姓名替换为随机报名编号；只做汇总统计时，不要收集姓名。

## 数据安全边界

- 程序会把原始 CSV 全量读入内存，并按“姓名”去重，不提供加密、权限控制、访问审计或自动删除。
- “查看个人信息隐私保护分析”只是文字建议，不代表程序已经实现这些保护措施。
- 不要把真实报名表、导出报告、手机号、学号或可识别个人的截图提交到 Git。
- 对外分享结果时只保留达到必要人数阈值的聚合统计，避免小样本组合识别个人。

## 技术实现

- 使用Python标准库，无需安装第三方依赖
- 使用`csv`模块处理CSV文件
- 使用`collections.Counter`高效统计数据
- 按姓名去重，适合当前演示数据；真实系统应使用不直接识别个人的报名编号

## 项目结构

- `campus_registration_analyzer.py`：主程序文件
- `sample_data.csv`：程序生成的示例数据（可选）
- `报名统计报告.txt`：程序生成的报告文件（可选）
